# بارراه | پلتفرم مدیریت حمل بار

نسخه نمایشی و RTL پنل مدیریت حمل‌ونقل جاده‌ای ایران. این پروژه گردش‌های اصلی ثبت بار، عملیات سفارش، مدیریت راننده و ناوگان، محتوای خدمات و رضایت مشتری را نمایش می‌دهد.

## قابلیت‌های پیاده‌سازی‌شده

- داشبورد فارسی و راست‌چین با شاخص‌های عملیاتی
- فهرست سفارش‌های حمل و وضعیت‌های مختلف سفر
- فرم ثبت درخواست حمل با انتخاب نوع خودرو
- صفحه مدیریت رانندگان و ناوگان
- مدیریت رضایت مشتری و ایده‌های محتوای قابل‌انتشار
- صفحه تنظیمات پایه مدیریت
- طراحی واکنش‌گرا برای دسکتاپ و موبایل

## فناوری

- Next.js با App Router
- React و TypeScript
- CSS اختصاصی، بدون کتابخانه رابط کاربری

## اجرای محلی

```bash
npm install
npm run dev
```

سپس نشانی `http://localhost:3000` را باز کنید.

## وضعیت این نسخه

داده‌ها در `lib/mock-data.ts` برای نمایش رابط قرار دارند و هنوز به پایگاه داده متصل نیستند. احراز هویت، سطح دسترسی واقعی، ذخیره سفارش، پیامک، پرداخت، نقشه و بارگذاری امن مدارک باید پس از انتخاب سرویس‌های مورد استفاده به پروژه اضافه شوند.

## حریم خصوصی محتوا

رضایت‌های مشتری فقط با اجازه انتشار قابل نمایش هستند. داده‌های شناسایی‌کننده، نشانی دقیق و جزئیات خصوصی بار نباید وارد محتوای عمومی شوند.
