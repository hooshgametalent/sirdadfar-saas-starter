# بارراه

[![CI](https://github.com/hooshgametalent/sirdadfar-saas-starter/actions/workflows/ci.yml/badge.svg)](https://github.com/hooshgametalent/sirdadfar-saas-starter/actions/workflows/ci.yml)

بارراه یک سامانه فارسی و راست‌به‌چپ برای مدیریت حمل‌ونقل جاده‌ای بار (باربری) است که به‌طور کامل روی **Laravel 13** ساخته شده است. صاحبان بار سفارش ثبت می‌کنند، رانندگان تأییدشده پیشنهاد قیمت می‌دهند و اپراتورها از پنل مدیریت، سفارش‌ها را از بررسی تا تحویل پیگیری می‌کنند.

## اصل اجرای مستقل (Self-hosted)

همه امکانات پروژه روی سرور خود پروژه نصب و اجرا می‌شود و برنامه در زمان اجرا به هیچ سرور خارجی نیاز ندارد:

- فونت وزیرمتن از بسته npm نصب و با Vite در `public/build` بسته‌بندی می‌شود. هیچ CDN یا سرویس فونت راه دور استفاده نمی‌شود.
- فایل‌های Filament و Livewire از خود برنامه سرو می‌شوند. سرویس آواتار خارجی Filament با آواتار حروف اول نام (SVG داخلی) جایگزین شده است.
- پیامک فعلا فقط در لاگ برنامه نوشته می‌شود و پرداخت‌ها به صورت دستی در پنل مدیریت ثبت می‌شوند. سرویس پیامک، درگاه پرداخت یا نقشه بعدا از طریق یک رابط (Interface) قابل اضافه شدن است.
- صف کارها، کش و نشست کاربران روی همان پایگاه داده MySQL است و به Redis یا سرویس دیگری نیاز نیست.
- ایمیج Docker در CI داخل یک شبکه بدون دسترسی به اینترنت اجرا و آزمایش می‌شود.

دسترسی به اینترنت فقط هنگام نصب و build لازم است (دریافت بسته‌های Composer و npm و ایمیج‌های پایه Docker).

## امکانات بر اساس نقش

| نقش | امکانات |
| --- | --- |
| بازدیدکننده | صفحه اصلی، مقاله‌ها و دسته‌بندی‌ها، صفحه‌های مسیر و خدمات، پرسش‌های متداول، نظرات مشتریان، تماس، `sitemap.xml` و `robots.txt` |
| صاحب بار (shipper) | ثبت‌نام و ورود با موبایل، ثبت سفارش حمل، مشاهده پیشنهادهای رانندگان، پذیرش پیشنهاد، لغو سفارش، پیگیری وضعیت و ثبت نظر پس از تحویل |
| راننده (driver) | تکمیل پروفایل و ناوگان، بارگذاری مدارک (روی دیسک خصوصی)، مشاهده بارهای باز، ارسال و پس گرفتن پیشنهاد قیمت، به‌روزرسانی وضعیت بارگیری، در مسیر و تحویل |
| اپراتور (operator) | پنل مدیریت: تأیید سفارش‌ها، تخصیص راننده، پیگیری وضعیت، تأیید رانندگان و مدارک، بررسی نظرات |
| ویرایشگر محتوا (content_editor) | پنل مدیریت: مقاله‌ها، صفحه‌ها، دسته‌بندی‌ها، پرسش‌های متداول و بررسی نظرات |
| مدیر (admin) | همه امکانات به‌اضافه کاربران و نقش‌ها، انواع خودرو، پرداخت‌های دستی، تنظیمات سایت و گزارش رویدادها (Audit log) |

وضعیت‌های سفارش: در انتظار بررسی، باز برای پیشنهاد، تخصیص‌یافته، بارگیری‌شده، در مسیر، تحویل‌شده و لغوشده. همه تغییر وضعیت‌ها داخل تراکنش پایگاه داده با قفل ردیف انجام و در تاریخچه سفارش و گزارش رویدادها ثبت می‌شوند.

## فناوری‌ها

- **Laravel 13** روی PHP 8.3 یا بالاتر
- **Livewire 4** برای سایت عمومی و پنل‌های صاحب بار و راننده
- **Filament 5** برای پنل مدیریت در مسیر `/admin`
- **MySQL 8.4** (در تست‌ها SQLite در حافظه)
- **Vite 8** و **Tailwind CSS 4** با فونت محلی **وزیرمتن**
- تاریخ شمسی با `morilog/jalali` و ارقام فارسی
- Docker با nginx، PHP-FPM و supervisor (صف کارها و زمان‌بند)

## اجرای محلی برای توسعه

پیش‌نیازها: PHP 8.3 یا بالاتر با افزونه‌های `pdo_mysql`، `intl`، `bcmath`، `gd`، `zip`، `mbstring` و `exif`، همچنین Composer 2، Node.js 22 و MySQL 8.

```bash
git clone https://github.com/hooshgametalent/sirdadfar-saas-starter.git
cd sirdadfar-saas-starter
cp .env.example .env
```

در فایل `.env` برای توسعه این مقادیر را تنظیم کنید:

```dotenv
APP_ENV=local
APP_DEBUG=true
APP_URL=http://127.0.0.1:8000
DB_DATABASE=barrah
DB_USERNAME=barrah
DB_PASSWORD=رمز-پایگاه-داده-شما
```

سپس:

```bash
composer install
php artisan key:generate
php artisan migrate --seed
npm install
npm run dev
```

و در یک ترمینال دیگر:

```bash
php artisan serve
php artisan queue:work   # اختیاری، برای کارهای صف
```

در محیط `local` دستور `migrate --seed` علاوه بر استان‌ها، شهرها و انواع خودرو، داده نمونه هم می‌سازد (کاربران خیالی `09120000001` تا `09120000009` با رمز `password`، سفارش‌ها و محتوای نمونه). در محیط production داده نمونه فقط با `DEMO_SEED=true` ساخته می‌شود.

### ساخت اولین مدیر

مقادیر زیر را در `.env` بگذارید و Seeder مدیر را اجرا کنید (این مقادیر نمونه هستند، مقدار خودتان را انتخاب کنید):

```dotenv
ADMIN_NAME="مدیر سامانه"
ADMIN_MOBILE=09xxxxxxxxx
ADMIN_PASSWORD=یک-رمز-قوی
```

```bash
php artisan db:seed --class='Database\Seeders\AdminUserSeeder' --force
```

سپس از نشانی `/admin` با شماره موبایل و رمز وارد شوید. بعد از ساخت مدیر می‌توانید `ADMIN_PASSWORD` را از `.env` پاک کنید.

## اجرای تست‌ها

```bash
vendor/bin/pint --test   # بررسی قالب‌بندی کد
php artisan test         # تست‌ها روی SQLite در حافظه
```

همین بررسی‌ها به‌اضافه migrate روی MySQL 8.4، ساخت ایمیج Docker و آزمون اجرای آن، با هر push در GitHub Actions اجرا می‌شوند.

## استقرار روی سرور

راهنمای کامل فارسی (اسکریپت `deploy.sh`، Docker Compose، اجرا بدون Docker، دامنه و HTTPS، پشتیبان‌گیری و رفع اشکال) در [docs/DEPLOYMENT.fa.md](docs/DEPLOYMENT.fa.md) آمده است. خلاصه:

```bash
sudo ./deploy.sh
```

## ساختار پروژه

```text
app/
  Contracts/        رابط‌ها (مثلا SmsSender)
  Enums/            نقش‌ها و وضعیت‌ها با برچسب فارسی
  Filament/         پنل مدیریت (Resource ها، صفحه تنظیمات، ویجت‌ها)
  Http/             کنترلرهای سایت عمومی، Middleware نقش‌ها
  Livewire/         ورود و ثبت‌نام، پنل صاحب بار و پنل راننده
  Models/           مدل‌های Eloquent
  Policies/         مجوزهای دسترسی
  Services/         چرخه سفارش، پیشنهادها، نظرات، تأیید رانندگان، پیامک
  Support/          تاریخ شمسی، موبایل، تنظیمات، پاک‌سازی HTML
config/freight.php  تنظیمات اختصاصی باربری
database/           migration ها، factory ها، seeder ها و فهرست استان‌ها و شهرها
resources/          قالب‌های Blade، CSS و JS
routes/web.php      مسیرهای سایت و پنل‌ها
tests/              تست‌های Feature و Unit
docker/             تنظیمات nginx، PHP، PHP-FPM، supervisor و entrypoint
Dockerfile          ایمیج production
docker-compose.yml  برنامه و MySQL
deploy.sh           نصب و به‌روزرسانی خودکار روی سرور
```

## تصمیم‌ها و پیش‌فرض‌ها

- ورود با شماره موبایل و رمز عبور. ارقام فارسی و عربی در شماره موبایل پذیرفته می‌شوند.
- ثبت‌نام عمومی فقط برای صاحب بار و راننده است. نقش‌های اپراتور، ویرایشگر محتوا و مدیر را فقط مدیر می‌سازد.
- راننده تا پیش از تأیید پروفایل نمی‌تواند پیشنهاد قیمت بدهد. شماره موبایل راننده فقط پس از تخصیص به صاحب بار نمایش داده می‌شود.
- پرداخت‌ها دستی هستند و در پنل مدیریت ثبت می‌شوند. درگاه پرداخت آنلاین وجود ندارد.
- پیامک‌ها در لاگ برنامه نوشته می‌شوند (`SMS_DRIVER=log`).
- استان‌ها، شهرها و انواع خودرو با Seeder ساخته می‌شوند و تکرار اجرای آن‌ها مشکلی ایجاد نمی‌کند.
- صف، کش و نشست روی پایگاه داده هستند.
- مدارک رانندگان روی دیسک خصوصی `storage/app/private` ذخیره و فقط از طریق کنترلر دارای بررسی مجوز نمایش داده می‌شوند. حداکثر حجم هر فایل با `FREIGHT_DOCUMENT_MAX_KB` تعیین می‌شود.
- منطقه زمانی پیش‌فرض `Asia/Tehran` و زبان پیش‌فرض فارسی است.
