# بارراه

پلتفرم مدیریت حمل‌ونقل جاده‌ای بار (باربری) که به‌طور کامل روی **Laravel 13**، **Livewire 4** و **Filament 5** ساخته می‌شود.

- همه امکانات روی سرور خود پروژه نصب و اجرا می‌شود و به هیچ سرور خارجی، CDN یا فونت راه دور نیاز ندارد.
- فونت وزیرمتن از طریق npm نصب و با Vite در خود پروژه بسته‌بندی می‌شود.
- پایگاه داده MySQL و صف، کش و نشست روی همان پایگاه داده.

راهنمای کامل نصب و استقرار در مراحل بعدی اضافه می‌شود.
